# Astra Email Templates - Professional Minimalist Design

## Overview

All email templates have been refactored with:
- **Brand**: Astra (AI-powered meeting scheduler)
- **Theme**: Blue light (soft blues, professional grays, clean whites)
- **Design**: Professional minimalist with HTML rendering
- **Footer**: AI disclaimer on all emails
- **Accessibility**: Clean typography, semantic HTML, responsive design

## Color Scheme

- **Primary Blue**: `#2563EB` (brand color, links, accents)
- **Light Blue**: `#F0F9FF` (highlights, backgrounds)
- **Dark Gray**: `#374151` (main text)
- **Soft Gray**: `#6B7280` (secondary text)
- **Border Gray**: `#E5E7EB` (dividers, borders)

## Email Types

### 1. Available Slots Email
**Purpose**: Present calendar slots for organizer to select meeting date

**Content**:
- Clean table layout showing available dates, phases, times
- Interactive styling with alternating row colors
- One-line instructions for responding

**Example Output**:
```
Available Meeting Slots
┌─────────────────────────────────────────────────────┐
│ 1 │ 2026-04-06 • morning    │ 09:00 – 10:00    │
│ 2 │ 2026-04-06 • afternoon  │ 14:00 – 15:00    │
│ 3 │ 2026-04-06 • evening    │ 18:00 – 19:00    │
└─────────────────────────────────────────────────────┘
Reply with option number (e.g., "1" or "Option 2")
```

### 2. Availability Request Email
**Purpose**: Collect time windows from participants

**Content**:
- Meeting date and phase clearly highlighted
- Multiple supported response formats listed
- Simple, direct instructions
- Minimal markup

**Example Output**:
```
Meeting Date Confirmation
Hi [Name],
[Organizer] has selected a date for an upcoming meeting.

┌────────────────────────────────────────────────┐
│ Date: 2026-04-06                                │
│ Preferred Phase: afternoon (morning/afternoon) │
└────────────────────────────────────────────────┘

Please Reply With Your Availability
Send your available time window in any format:
• "Available from 09:00 to 11:00"
• "09:00 to 11:00"
• "09:00–11:00"

We'll combine everyone's availability to find the best time.
```

### 3. Participant Confirmation Email
**Purpose**: Notify participant their meeting is scheduled

**Content**:
- Meeting title and date/time in participant's timezone
- Direct "Join Meeting" button (blue)
- Calendar link for reference
- Reassurance about timezone considerations

**Example Output**:
```
Meeting Scheduled
Hi [Name],
Your meeting has been scheduled!

┌────────────────────────────────────────────────┐
│ [Meeting Title]                                │
│ 2026-04-06 at 14:30 – 15:30                   │
│ America/New_York                              │
└────────────────────────────────────────────────┘

[Join Meeting Button]
View in Calendar

Your availability and timezone preferences were considered 
in scheduling this time. The meeting has been added to your 
Google Calendar.
```

### 4. Organizer Explanation Email
**Purpose**: Show organizer why the slot was selected and alternatives

**Content**:
- Selected slot with full breakdown by timezone
- Score explanation (why this one is best)
- List of other options considered (if multiple)
- Priority weighting breakdown
- All participants' local times

**Example Output**:
```

The meeting has been automatically scheduled using optimal 
time analysis.

┌────────────────────────────────────────────────┐
│ Date: 2026-04-06                               │
│ Time: 2026-04-06T17:30:00.000Z                │
│ Score: 13.5 (highest)                         │
│                                                │
│ Local Times:                                   │
│ • Vishwanath: 13:30 – 14:30 (America/New_York)│
│ • Abhinav: 18:30 – 19:30 (Europe/London)     │
└────────────────────────────────────────────────┘

[Join Meeting Button]
View in Calendar

Why This Time?
This slot scored highest (13.5) by optimizing for:
• Participant availability overlap
• Priority weighting (Vishwanath: 3, Abhinav: 2)
• Business hour preferences (9 AM – 5 PM)
• Timezone fairness (reasonable local times)

Other Options Considered
┌────────────────────────────────────────────────┐
│ Option 2 │ Score: 12.0 • Vishwanath: 13:00... │
│ Option 3 │ Score: 11.5 • Vishwanath: 14:00... │
└────────────────────────────────────────────────┘

All participants have been notified and the meeting is on 
their calendars.
```

## AI Disclaimer Footer

Every email includes:

```
---

This email was generated by Astra, an AI-powered meeting scheduler. 
Our system analyzes participant availability, timezones, and priorities 
to optimize meeting scheduling. For questions, contact the meeting 
organizer.
```

**Styling**:
- Separated by top border
- 12px font size (smaller for footer)
- Soft gray color (#6B7280)
- Professional, informative tone
- No promotional language

## Template Implementation

### MeetingService Methods

All methods are in `src/services/meeting-service.js`:

1. **`emailHeader()`** - Returns opening HTML boilerplate
2. **`emailFooter()`** - Returns AI disclaimer + closing tags
3. **`emailSection(title, content)`** - Wraps content with styling
4. **`emailHighlight(text)`** - Creates highlighted box
5. **`formatAvailableSlots(slots)`** - Full HTML email for calendar selection
6. **`formatAvailabilityRequest(slot, organizer)`** - Full HTML email for availability collection
7. **`formatParticipantConfirmation(participant, slot, links, title)`** - Full HTML email for participant notification
8. **`formatOrganizerExplanation(slots, selected, participants, links, title)`** - Full HTML email for organizer breakdown

### Email Sending

Updated in `src/services/email-sender.js`:
- Changed from `text: body` to `html: body` in both `sendEmail()` and `sendReply()`
- HTML emails now render with full styling
- All emails include Astra branding and AI disclaimer

## Responsive Design

All templates are mobile-responsive:
- Maximum width: 600px (readable on all devices)
- Font stack: System fonts (fast loading, native feel)
- Line height: 1.6 (excellent readability)
- Padding/margins: Consistent 12-20px spacing
